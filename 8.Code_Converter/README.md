# 🔄 Code Converters in Digital Electronics

## 📘 Overview
This project demonstrates the implementation of fundamental **code converters** used in digital systems. Code converters are essential for translating one form of binary representation into another, enabling interoperability between different digital modules and simplifying arithmetic or display operations.

---

## 🎯 Objectives
- Implement and simulate key code converters using Verilog.
- Understand the logic behind binary transformations.
- Provide modular, reusable, and beginner-friendly designs.
- Visualize behavior through waveform simulation.

---

## 🧠 Included Converters

| Converter Type       | Description                                      |
|----------------------|--------------------------------------------------|
| **[Binary to Gray](./8.2.Binary_to_Gray)**   | Converts binary input to Gray code (single-bit change between successive values). |
| **[Gray to Binary](./8.1.Gray_to_Binary)**   | Reverses Gray code back to binary.               |
| **[Binary to BCD](./8.3.Binary_To_BCD)** | Binary Coded Decimal |
| **[BCD to Binary](./8.4.BCD_To_Binary)** | Converts back BCD input to Binary . |

---

## 🛠️ Technologies Used
- **Verilog HDL** for hardware description.
- **Testbenches** for simulation and verification.
- **EDA Playground / ModelSim / Icarus Verilog** for waveform analysis.
